## 1. 引言

### 1.1 编写目的

本文档将《需求分析文档》中的需求**规格化**，为后续设计、开发、测试与验收提供基线。每个功能需求给出唯一编号、输入/输出与**可测试的验收准则**，并通过第 8 节追踪矩阵与《接口文档》《任务分工文档》关联，形成需求 → 接口 → 负责人的可追踪闭环。

### 1.2 项目背景

传统仓储库位分配依赖人工经验或简单规则，缺乏对重量、周转频次、出库优先级等要素的综合量化，导致高频货远离出库口、重货置于高层等问题。本系统通过建模与仿真，实现库位智能推荐、多策略仿真对比与效率评估，定位为**教学与辅助决策工具**（小型单体应用，非生产级 WMS）。

### 1.3 术语与缩写

| 术语 | 说明 |
| --- | --- |
| 库位 | 最小存储单元，有唯一编码与坐标 |
| SKU | 最小库存单元，区分货物种类 |
| 周转频次 | 单位时间内某货物的出库/搬运次数 |
| 出库优先级 | 货物出库的紧急程度权重 |
| 分配方案 | 一套完整库位分配结果（含策略参数与占用状态） |
| RBAC | 基于角色的访问控制（Role-Based Access Control） |
| 曼哈顿距离 | `d = |x1-x2| + |y1-y2|` |

## 2. 总体描述

### 2.1 产品定位

小型智能仓储库位分配仿真系统，提供：库位智能推荐、多策略入库仿真、订单出库仿真与路程统计、多方案对比与优化建议、基于角色的权限控制。

### 2.2 用户角色

| 角色 | 标识 | 主要职责 |
| --- | --- | --- |
| 系统管理员 | admin | 用户/角色/权限、基础数据、系统配置 |
| 仓库操作员 | operator | 货物/订单录入、库位推荐、运行入库仿真 |
| 分析人员 | analyst | 运行仿真、查看结果、方案对比与报告导出 |
| 只读访客 | viewer | 仅查看仓库布局与仿真结果 |

### 2.3 运行环境

| 项 | 要求 |
| --- | --- |
| 后端 | Java 17 + Spring Boot 3.2 + MyBatis-Plus + MySQL 8 |
| 前端 | Vue 3 + TypeScript，支持 Chrome/Edge/Firefox 最新版 |
| 部署 | 前后端分离，HTTP/JSON 通信 |

### 2.4 设计约束

- 单仓库规模 ≤ 1 万库位，推荐计算与仿真秒级完成（≤ 5s）。
- 单租户系统，RBAC 仅控制系统内角色操作边界。
- 本期不做：硬件对接（AGV/堆垛机）、实时监控、条码/RFID、多仓库调拨、多租户。

### 2.5 假设与依赖

- 路程默认按二维曼哈顿距离计算，出库口位于仓库一侧。
- 拣选方式本期简化为按单拣选。
- 仿真结果与实际作业存在差异，需在文档中说明假设。

## 3. 功能需求

> 需求编号沿用《需求分析文档》，保证追踪一致性。优先级：P0（关键路径）/ P1（重要）/ P2（一般）。负责人对应《任务分工文档》a/b/c。

### 3.1 模块一：基础数据管理（负责人 a）

#### FR-1.1 仓库建模

- **描述**：支持创建/编辑仓库（长/宽/高或货架行列层数量）、货架与库位建模；库位唯一编码（如 `A-01-03-02`）；平面图展示货架与库位布局。
- **输入**：仓库尺寸/行列层；货架巷道/层/列；库位编码、坐标、层、容量。
- **输出**：仓库布局数据，前端平面图渲染。
- **验收准则**：
  1. 可创建仓库并录入货架/库位，库位编码全局唯一；
  2. 平面图正确展示库位位置与状态（空闲/占用），出库口有标记；
  3. 库位坐标与层信息可被推荐/仿真模块读取。
- **对应接口**：API-016 ~ API-028。

#### FR-1.2 货物管理（SKU）

- **描述**：录入货物属性：名称、SKU 编码、重量、周转频次、出库优先级、尺寸/品类；支持 CSV/Excel 批量导入。
- **验收准则**：
  1. 可增删改查 SKU，属性完整；
  2. 批量导入支持 CSV/Excel，非法行给出错误提示；
  3. 重量/频次/优先级可被推荐引擎正确读取。
- **对应接口**：API-029 ~ API-032、API-037、API-039。

#### FR-1.3 订单管理

- **描述**：录入出库订单（SKU、数量、优先级、下达时间）；支持生成随机测试订单集（用于仿真）。
- **验收准则**：
  1. 可增删改查订单；
  2. 可生成指定数量、优先级范围、时间范围的随机订单集；
  3. 订单可按优先级 + 下达时间排序供出库仿真使用。
- **对应接口**：API-033 ~ API-036、API-038、API-040、API-062。

### 3.2 模块二：库位智能推荐（核心，负责人 b）

#### FR-2.1 推荐引擎

- **描述**：根据货物属性对当前**所有空闲库位**计算推荐评分并排序。评分因素：重量（默认 30%）、周转频次（40%）、出库优先级（20%）、其他（10%），权重可配。
- **输入**：SKU、仓库；候选空闲库位集合。
- **输出**：候选库位评分降序列表（含总分与分项得分）。
- **验收准则**：
  1. 对全部空闲库位评分并降序返回；
  2. 每个候选含总分与四类分项得分（重量/频次/优先级/其他）；
  3. 各分项归一化到 [0,1]，权重之和恒为 1；
  4. 重货倾向低层、高频/高优先级货倾向近出库口（规则可验证）；
  5. 万库位规模计算 ≤ 5s。
- **对应接口**：API-041。

#### FR-2.2 推荐结果展示

- **描述**：以列表（评分降序）+ 平面图高亮两种方式展示推荐库位，展示分项得分与推荐理由；支持一键「采用推荐」完成入库并更新库位状态。
- **验收准则**：
  1. 列表与平面图高亮同步展示；
  2. 展示每个候选的分项得分与理由；
  3. 采用推荐后库位状态由空闲变占用。
- **对应接口**：API-042、API-043。

#### FR-2.3 权重可配置

- **描述**：各因子权重、库位分层规则（如「第 1 层放重货」）可由管理员调整，调整后重新计算推荐。
- **验收准则**：
  1. 权重调整后重新评分生效；
  2. 权重之和校验为 1，非法输入被拒绝；
  3. 分层规则变更后重算推荐。
- **对应接口**：API-044 ~ API-048。

### 3.3 模块三：入库策略仿真（负责人 c）

#### FR-3.1 内置策略

- **描述**：内置六种入库策略：随机、就近、分区存储、分级存储（按频次/重量）、智能推荐（评分）、FIFO 空位。
- **验收准则**：
  1. 六种策略均可选择并执行；
  2. 策略采用插件式设计，新增策略不改核心逻辑（NFR-3）。
- **对应接口**：API-054。

#### FR-3.2 仿真执行

- **描述**：选定策略，将一批货物按序入库；记录每次选位与理由，形成库位分配方案；支持清空重置后换策略重新仿真。
- **验收准则**：
  1. 每次入库记录所选库位与理由；
  2. 生成可保存的分配方案；
  3. 清空重置后可重新仿真。
- **对应接口**：API-055 ~ API-057。

### 3.4 模块四：出库仿真与路程统计（负责人 c）

#### FR-4.1 出库仿真

- **描述**：按订单出库顺序（优先级 + 下达时间排序）逐单检索货物所在库位，模拟拣选（按单拣选）。
- **验收准则**：
  1. 按优先级 + 下达时间正确排序出库；
  2. 逐单检索到对应库位并模拟拣选。
- **对应接口**：API-058。

#### FR-4.2 路程统计

- **描述**：统计单订单路程、全部订单总路程、平均每单路程、可选耗时估算（设平均移动速度）；路程按曼哈顿距离（可扩展折线/欧氏）。
- **验收准则**：
  1. 总路程、平均路程、单订单路程计算正确（可与人工样例比对）；
  2. 距离默认曼哈顿公式，口径统一。
- **对应接口**：API-060。

#### FR-4.3 可视化

- **描述**：平面图绘制拣选路径；输出路程统计图表与汇总表格。
- **验收准则**：
  1. 拣选路径在平面图正确绘制；
  2. 统计图表与汇总表格正确展示。
- **对应接口**：API-059、API-061。

### 3.5 模块五：方案对比与优化建议（负责人 b）

#### FR-5.1 多方案对比

- **描述**：保存多个分配方案（不同策略）及仿真结果；以表格 + 图表对比总路程、平均路程、高频货平均距离、重货层位违规数等指标。
- **验收准则**：
  1. 可保存并列出多个方案；
  2. 对比指标齐全，表格与图表展示正确。
- **对应接口**：API-049 ~ API-051。

#### FR-5.2 优化建议

- **描述**：基于对比结果自动生成文字建议（如「方案 B 相比方案 A 总路程下降 18.3%」）；支持导出报告（Markdown/CSV/PDF 任选其一）。
- **验收准则**：
  1. 自动生成可读的优化建议文字；
  2. 报告可导出（至少一种格式）。
- **对应接口**：API-052、API-053。

### 3.6 模块六：用户与权限管理 RBAC（负责人 a）

| 编号 | 描述 | 验收准则 |
| --- | --- | --- |
| FR-RBAC-1 | 用户注册/禁用、密码管理、登录认证与会话 | 可注册/禁用用户，密码加密存储，登录成功返回凭证 |
| FR-RBAC-2 | 角色创建、删除与权限分配（菜单 + 操作） | 可增删角色并分配权限 |
| FR-RBAC-3 | 权限校验覆盖页面与后端接口（前端显隐 + 后端强制鉴权） | 前端按角色显隐，后端接口强制校验 |
| FR-RBAC-4 | 默认内置 admin/operator/analyst/viewer 四角色，权限可调整 | 四角色默认可用，权限可被管理员调整 |
| FR-RBAC-5 | 越权访问给出明确提示（前端拦截 + 接口 403） | 越权返回 403，前端给出提示 |

- **对应接口**：API-001 ~ API-015（鉴权中间件覆盖全部接口）。

## 5. 业务规则与算法

### 5.1 库位评分模型

```
Score(L) = W_w × S_weight(L) + W_f × S_freq(L) + W_p × S_priority(L) + W_o × S_other(L)
```

- `S_weight`：货物越重、库位层越低（层号小），得分越高。
- `S_freq`：周转频次越高、离出库口越近，得分越高。
- `S_priority`：出库优先级越高、越靠近出库口，得分越高。
- `S_other`：品类匹配、空位连续性等附加分。
- 各分项归一化到 [0,1]，权重 `W_*` 之和为 1（默认 0.30 / 0.40 / 0.20 / 0.10）。

### 5.2 距离计算

默认曼哈顿距离 `d = |x1-x2| + |y1-y2|`（二维）；可扩展为三维折线/欧氏，本期先支持二维。

### 5.3 出库优先级

高优先级订单先出库（按优先级 + 下达时间排序）；优先级同时作为推荐靠近出库口的加权因素。

### 5.4 约束

- 一库位同一时刻最多存放一种货物（或同 SKU 同批次）。
- 重货禁止分配到超过预设层高（阈值可配）。
- 货物尺寸不得超出库位容量（录入尺寸则校验）。

## 9. 验收标准

1. 可录入仓库与货物，平面图正确展示库位布局。
2. 入库时给出带评分与理由的库位推荐排序，支持权重调整。
3. 至少支持 4 种入库策略仿真（含智能推荐策略）。
4. 可仿真订单出库并正确统计总搬运路程、平均路程。
5. 可对比至少 2 个方案，输出量化对比与优化建议文字。
6. 支持数据导入导出，核心算法具备基本单元测试。
7. RBAC：不同角色登录后仅能访问被授权功能，越权被正确拦截（403）。
8. 提供使用说明文档与算法说明文档。
