## 1. 项目概述

### 1.1 背景

传统仓储作业中，库位分配多依赖人工经验或简单规则（如先入先出、就近空位），缺乏对货物重量、周转频次、出库优先级等要素的综合量化考量。这导致高频货物可能被存放在远离出库口的位置、重货被置于高层货架等不合理现象，进而降低出库效率、增加搬运路程与作业成本。

本项目旨在构建一个**小型智能仓储库位分配仿真系统**，通过建模与仿真手段，让使用者能够：

1. 依据货物多维属性自动获得最优库位推荐；
2. 模拟不同入库策略下的订单出库过程；
3. 统计搬运路程、评估出库效率；
4. 对比多种库位分配方案，并输出优化建议。

系统定位为**教学与辅助决策工具**，规模为小型单体应用，而非生产级 WMS（仓储管理系统）。

### 1.2 目标

- **智能推荐**：基于货物重量、周转频次、出库优先级综合评分，自动推荐最优库位。
- **策略仿真**：支持多种入库策略（如随机、就近、分区、按频次/重量分级等）的仿真对比。
- **效率评估**：仿真订单出库流程，统计搬运路程、出库耗时等效率指标。
- **方案对比**：对多个分配方案进行量化对比，并给出可读的优化建议。
- **权限管理**：基于角色的访问控制（RBAC），保障不同角色操作边界与数据安全。

### 1.3 范围

**范围内：**

- 仓库/货架/库位的基础数据建模。
- 货物入库时的库位智能推荐（评分排序）。
- 多种入库策略的仿真执行。
- 订单出库仿真与搬运路程统计。
- 多方案对比与优化建议输出。
- 基于角色的权限控制（RBAC）：用户、角色、权限管理。

**范围外（本期不做）：**

- 与真实硬件设备（AGV、传送带、堆垛机）的对接。
- 实时仓储监控、条码/ RFID 集成。
- 多仓库、跨仓调拨、库存预警等复杂 WMS 功能。
- 多租户体系（系统为单租户，RBAC 仅作用于本系统内的角色与权限）。

### 1.4 术语表

| 术语 | 说明 |
| --- | --- |
| 库位 | 仓库中用于存放货物的最小存储单元，有唯一编码与空间坐标 |
| 货架 | 多个库位的集合，具有巷道、层、列等属性 |
| 出库口/拣选口 | 订单出库作业的起点/终点，通常位于仓库一侧 |
| 周转频次 | 单位时间内某类货物的出库/搬运次数 |
| 出库优先级 | 货物出库的紧急程度或先后顺序权重 |
| 搬运路程 | 从库位到出库口（或库位间）的移动距离，常按曼哈顿距离或折线距离计算 |
| 入库策略 | 决定新货物放入哪个库位的规则/算法 |
| 分配方案 | 一套完整的库位分配结果（含规则参数与库位占用状态） |
| SKU | 最小库存单元，用于区分不同货物种类 |
| RBAC | 基于角色的访问控制（Role-Based Access Control） |

## 2. 用户、角色与权限（RBAC）

系统采用基于角色的访问控制（RBAC）模型：`用户 → 角色 → 权限`，权限可配置到菜单与操作级。系统内置以下角色，管理员可自定义角色并分配权限。

### 2.1 角色定义

| 角色 | 描述 | 主要职责 |
| --- | --- | --- |
| 系统管理员 (admin) | 最高权限，负责系统与用户管理 | 用户/角色/权限管理、基础数据管理、系统配置 |
| 仓库操作员 (operator) | 执行日常入库作业 | 货物/订单录入、库位推荐、运行入库仿真 |
| 分析人员 (analyst) | 负责策略评估与报告 | 运行仿真、查看结果、方案对比与报告导出 |
| 只读访客 (viewer) | 仅查看结果 | 查看仓库布局与仿真结果，无修改权限 |

### 2.2 权限矩阵

| 权限 | 管理员 | 操作员 | 分析人员 | 只读访客 |
| --- | :-: | :-: | :-: | :-: |
| 用户/角色/权限管理 | ✔ | ✘ | ✘ | ✘ |
| 仓库/货架/库位管理 | ✔ | ✘ | ✘ | ✘ |
| 货物/订单管理（增删改） | ✔ | ✔ | ✘ | ✘ |
| 库位智能推荐 | ✔ | ✔ | ✘ | ✘ |
| 入库策略仿真 | ✔ | ✔ | ✔ | ✘ |
| 仿真结果查看 | ✔ | ✔ | ✔ | ✔ |
| 方案对比与优化建议 | ✔ | ✘ | ✔ | ✔ |
| 报告导出 | ✔ | ✘ | ✔ | ✘ |
| 系统配置（权重/参数） | ✔ | ✘ | ✘ | ✘ |

### 2.3 RBAC 功能要点

- **FR-RBAC-1**：支持用户注册/禁用、密码管理、登录认证与会话管理。
- **FR-RBAC-2**：支持角色的创建、删除与权限分配（菜单权限 + 操作权限）。
- **FR-RBAC-3**：权限校验覆盖页面访问与后端接口（前端控制显隐，后端强制鉴权）。
- **FR-RBAC-4**：默认内置上表四种角色，权限可被管理员调整。
- **FR-RBAC-5**：越权访问时给出明确提示（前端拦截 + 接口返回 403）。

> 说明：本系统为单租户，RBAC 仅控制系统内不同角色的操作边界，不涉及跨租户数据隔离。

## 3. 功能需求

### 3.1 功能总览

```
┌─────────────────────────────────────────────────────────┐
│                   仓储库位分配仿真系统                      │
├──────────────┬──────────────┬──────────────┬─────────────┤
│  基础数据管理 │  库位智能推荐 │  入库策略仿真 │ 方案对比分析  │
│  仓库/货架/  │  货物属性评分 │  策略选择配置 │  多方案指标   │
│  库位/货物   │  最优库位排序 │  订单出库仿真 │  对比与建议   │
│  /订单管理   │  推荐结果展示 │  路程统计     │  报告导出    │
├──────────────┴──────────────┴──────────────┴─────────────┤
│                用户与权限管理（RBAC）                       │
└─────────────────────────────────────────────────────────┘
```

### 3.2 模块一：基础数据管理

**FR-1.1 仓库建模**

- 支持创建/编辑仓库，配置：长、宽、高（或货架行列层数量）。
- 支持可视化展示货架与库位布局（二维平面图即可）。
- 库位唯一编码，例如 `A-01-03-02`（巷道-列-层）。

**FR-1.2 货物管理（SKU）**

- 录入货物基础属性：名称、SKU 编码、**重量**、**周转频次**、**出库优先级**、尺寸/品类。
- 支持批量导入（CSV/Excel）。

**FR-1.3 订单管理**

- 录入出库订单：包含 SKU、数量、优先级、下达时间。
- 支持生成随机测试订单集（用于仿真）。

### 3.3 模块二：库位智能推荐（核心）

**FR-2.1 推荐引擎**

系统根据货物属性，对当前**所有空闲库位**计算推荐评分，输出排序结果。评分考虑：

| 因素 | 说明 | 权重（可配） |
| --- | --- | --- |
| 重量 | 重货倾向低层，轻货可放高层 | 默认 30% |
| 周转频次 | 高频货靠近出库口/黄金区 | 默认 40% |
| 出库优先级 | 高优先级货物靠近出库口 | 默认 20% |
| 其他（品类/尺寸/空位连续性） | 附加约束 | 默认 10% |

**FR-2.2 推荐结果展示**

- 以列表（评分降序）与仓库平面图高亮两种方式展示推荐库位。
- 展示每个候选库位的分项得分与总分，便于理解推荐理由。
- 支持一键"采用推荐"完成入库并更新库位占用状态。

**FR-2.3 权重可配置**

- 各影响因子的权重、库位分层规则（如"第 1 层放重货"）允许管理员调整，调整后重新计算推荐。

### 3.4 模块三：入库策略仿真

**FR-3.1 内置策略**

| 策略 | 描述 |
| --- | --- |
| 随机分配 | 随机选择空闲库位 |
| 就近分配 | 选择离出库口最近的空闲库位 |
| 分区存储 | 按品类/频次分区，区内就近 |
| 分级存储（按频次/重量） | 高频/轻货黄金区，重货低层 |
| 智能推荐（评分） | 使用 FR-2 的评分模型 |
| 先入先出（FIFO 空位） | 按空位编号顺序分配 |

**FR-3.2 仿真执行**

- 选定一种入库策略，将一批货物/订单按序完成入库。
- 记录每次入库选择的库位与理由，形成**库位分配方案**。
- 支持"清空重置"后以另一种策略重新仿真。

### 3.5 模块四：出库仿真与路程统计

**FR-4.1 出库仿真**

- 按订单出库顺序，逐单检索对应货物所在库位，模拟拣选过程。
- 支持设置拣选方式（如按单拣选 / 批量拣选，本期可简化为按单）。

**FR-4.2 路程统计**

- 统计指标包括：
  - 单订单搬运路程；
  - 全部订单**总搬运路程**；
  - 平均每单路程；
  - （可选）出库耗时估算（设平均移动速度）。
- 路程按曼哈顿距离（或用户选择的折线/欧氏距离）计算。

**FR-4.3 可视化**

- 在平面图上绘制拣选路径。
- 输出路程统计图表与汇总表格。

### 3.6 模块五：方案对比与优化建议

**FR-5.1 多方案对比**

- 保存多个分配方案（不同策略）及其仿真结果。
- 以表格 + 图表对比各方案的**总路程、平均路程、高频货平均距离、重货层位违规数**等指标。

**FR-5.2 优化建议**

- 基于对比结果，自动生成文字建议，例如：
  - "方案 B 相比方案 A 总搬运路程下降 18.3%，建议采用 B"。
  - "高频 SKU-001 当前存放在远端库位，建议调整至黄金区"。
- 支持导出对比报告（Markdown/CSV/PDF 任选其一即可）。

### 3.7 模块六：用户与权限管理（RBAC）

详见第 2 节，功能要点对应 FR-RBAC-1 ~ FR-RBAC-5。

## 4. 业务规则与算法

### 4.1 库位评分模型

对候选空闲库位 `L`，综合得分：

```
Score(L) = W_w × S_weight(L) + W_f × S_freq(L) + W_p × S_priority(L) + W_o × S_other(L)
```

- `S_weight`：货物越重、库位层越低，得分越高（低层=层号小）。
- `S_freq`：货物周转频次越高、库位离出库口越近，得分越高。
- `S_priority`：出库优先级越高、库位越靠近出库口，得分越高。
- `S_other`：品类匹配、空位连续性等附加分。
- 各分项归一化到 `[0, 1]`，权重 `W_*` 之和为 1。

> 具体权重默认值见 FR-2.1，管理员可配置。

### 4.2 距离计算

- 默认采用**曼哈顿距离**：`d = |x1-x2| + |y1-y2|`（二维平面）。
- 若考虑货架垂直层高，可扩展为三维折线距离，本期可先支持二维。

### 4.3 出库优先级处理

- 高优先级订单先于低优先级订单出库（仿真时按优先级 + 下达时间排序）。
- 出库优先级在库位推荐中作为靠近出库口的加权因素。

### 4.4 约束

- 一个库位同一时刻最多存放一种货物（或同 SKU 同批次）。
- 重货禁止分配到超过预设层高（可配置阈值）。
- 货物尺寸不得超出库位容量（若录入尺寸，则校验）。

## 6. 数据需求

### 6.1 核心实体

```
仓库 (Warehouse)
  ├── 货架 (Rack)
  │     └── 库位 (Location)：编码、坐标、层、状态(空闲/占用)、容量
  ├── 货物 (SKU)：编码、名称、重量、周转频次、出库优先级、品类、尺寸
  ├── 订单 (Order)：编号、SKU、数量、优先级、下达时间、状态
  └── 分配方案 (Plan)：策略名、参数、库位占用映射、仿真结果

用户与权限 (RBAC)
  ├── 用户 (User)：账号、密码(加密)、状态、关联角色
  ├── 角色 (Role)：名称、描述、权限集合
  └── 权限 (Permission)：标识、名称、类型(菜单/操作)
```

### 6.2 存储

- 使用MySQL数据库存储。
- 支持 JSON/CSV 格式的导入导出。

## 7. 系统架构（逻辑视图）

建议采用**前后端分离 + 轻量后端**的单体架构，便于 3 人并行开发。

```
┌─────────────┐      HTTP/JSON      ┌──────────────────────┐
│   前端 Web   │ ──────────────────▶ │      后端服务          │
│  可视化/交互  │ ◀────────────────── │  REST API             │
└─────────────┘                     │  ├─ 数据管理模块       │
                                    │  ├─ 推荐引擎           │
                                    │  ├─ 仿真引擎           │
                                    │  ├─ 统计/对比模块      │
                                    │  └─ 用户权限模块(RBAC) │
                                    └──────────┬───────────┘
                                               │
                                        ┌──────▼──────┐
                                        │  数据库/存储  │
                                        └─────────────┘
```

- **推荐引擎**与**仿真引擎**为独立模块，便于算法迭代与单元测试。
- **用户权限模块（RBAC）**以中间件/拦截器方式统一鉴权，后端接口强制校验。
- 建议技术栈（可选）：前端 Vue/React + 可视化库（ECharts / 自绘 Canvas）；后端 Python（FastAPI/Flask）或 Node.js；数据库 MySQL。

## 8. 界面需求（示例）

1. **登录页**：账号密码登录，按角色加载对应菜单。
2. **仓库总览页**：平面图展示货架/库位，颜色区分空闲/占用，出库口标记。
3. **入库推荐页**：选择货物 → 显示推荐库位排序 + 平面图高亮 → 采用推荐。
4. **仿真配置页**：选择入库策略、设置订单集、开始仿真。
5. **结果对比页**：多方案指标表格、柱状/折线图、优化建议文字。
6. **用户与权限页**（管理员）：用户管理、角色管理、权限分配。

## 10. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 评分模型权重不合理导致推荐结果缺乏说服力 | 高 | 与用户确认权重与规则，提供可配置能力 |
| 仿真与真实作业差异大 | 中 | 明确仿真假设并在文档中说明；预留参数校准入口 |
| 距离/路程计算口径不统一 | 中 | 早期统一距离定义（曼哈顿 vs 折线） |
| 三人并行开发接口不一致 | 中 | 提前定义 REST API 契约与数据结构 |
| RBAC 鉴权遗漏导致越权 | 高 | 后端接口统一走鉴权中间件，前端仅做显示控制 |

## 11. 验收标准

1. 可录入仓库与货物，并在平面图正确展示库位布局。
2. 入库时能给出带评分与理由的库位推荐排序，并支持权重调整。
3. 至少支持 4 种入库策略的仿真（含智能推荐策略）。
4. 能仿真订单出库并正确统计总搬运路程、平均路程。
5. 能对比至少 2 个方案，并输出量化对比与优化建议文字。
6. 支持数据导入导出，核心算法具备基本单元测试。
7. RBAC：不同角色登录后仅能看到/操作被授权功能，越权访问被正确拦截。
8. 提供使用说明文档。
