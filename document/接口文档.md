## 1. 接口通用约定

### 1.1 基础信息

| 项 | 约定 |
| --- | --- |
| Base URL | `/api/v1` |
| 数据格式 | 请求/响应均为 `application/json`（导入导出除外） |
| 认证方式 | 登录后返回 Token，请求头携带 `Authorization: Bearer <token>` |
| 字符编码 | UTF-8 |

### 1.2 统一响应结构

成功与失败均返回统一 JSON 结构：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| 字段 | 说明 |
| --- | --- |
| `code` | 0 表示成功；非 0 为业务错误码 |
| `message` | 提示信息 |
| `data` | 业务数据（可为对象、数组或 null） |

分页列表统一返回：

```json
{
  "code": 0,
  "message": "success",
  "data": { "list": [], "total": 0, "page": 1, "page_size": 20 }
}
```

### 1.3 HTTP 状态码与错误码

| HTTP | 含义 | 说明 |
| --- | --- | --- |
| 200 | 成功 | `code = 0` |
| 400 | 参数错误 | 请求体校验失败 |
| 401 | 未认证 | 未登录或 Token 失效 |
| 403 | 越权 | 已登录但无权限（对应 FR-RBAC-5，由 **a 的鉴权中间件**统一拦截） |
| 404 | 不存在 | 资源不存在 |
| 422 | 业务校验失败 | 如库位已占用、重货层高违规等 |
| 500 | 服务器错误 | 系统异常 |

### 1.4 权限标识（对应需求文档 2.2 权限矩阵）

| 权限码 | 含义 | 允许角色 |
| --- | --- | --- |
| `user:manage` | 用户/角色/权限管理 | admin |
| `warehouse:manage` | 仓库/货架/库位管理 | admin |
| `sku:manage` | 货物/订单管理（增删改） | admin、operator |
| `recommend:view` | 库位智能推荐 | admin、operator |
| `sim:run` | 入库策略仿真 | admin、operator、analyst |
| `sim:view` | 仿真结果查看 | admin、operator、analyst、viewer |
| `compare:view` | 方案对比与优化建议 | admin、analyst、viewer |
| `report:export` | 报告导出 | admin、analyst |
| `config:manage` | 系统配置（权重/参数） | admin |

> **鉴权说明**：所有接口默认经过 **a** 开发的鉴权中间件（A-B8，`requirePermission('权限码')`）校验；本文标注的开发者是各接口的**功能实现方**。

## 2. 接口总览与开发者统计

| 开发者 | 负责模块 | 接口编号 | 接口数 |

| **a** | 认证/用户/角色/权限、仓库/货架/库位、SKU、订单、导入导出 | API-001 ~ API-040 | 40 |

**示例：计算推荐（API-041，对应 FR-2.1 / FR-2.2）**

```http

{ "skuId": 3, "warehouseId": 1, "topN": 10 }
```

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "recommendationId": "REC-20260910-0001",
    "sku": { "skuCode": "SKU-001", "weight": 50, "turnoverRate": 0.9, "priority": 5 },
    "candidates": [
      {
        "locationId": 1001,
        "code": "A-01-03-02",

  }

```

## 15. 开发者归属汇总

| 开发者 | 接口范围 | 接口数 | 模块特点 |
| --- | --- | :-: | --- |
| **a** | API-001 ~ API-040 | 40 | 认证/RBAC、仓库/货架/库位、SKU、订单、导入导出（CRUD 为主） |
| **b** | API-041 ~ API-053 | 13 | 推荐引擎、权重规则配置、方案对比、建议与报告（算法为主） |
| **c** | API-054 ~ API-062 | 9 | 入库仿真、出库仿真与路程统计、随机订单集（仿真为主） |

### 跨模块协作点（对应《任务分工文档》第 6 节契约）

| 协作点 | 提供方 | 消费方 | 接口体现 |
| --- | --- | --- | --- |
| 评分接口 | b（API-041） | c（`smart` 策略，API-055） | 智能推荐策略复用 |
| 库位状态更新 | a（库位模型） | b（API-043 采用推荐） | 数据结构冻结 |
| 分配方案数据 | c（API-055 产生） | b（API-049~053 对比/报告） | 方案对象字段冻结 |
| 随机订单集 | c（API-062） | c（API-055/058 仿真消费） | 内部闭环 |
